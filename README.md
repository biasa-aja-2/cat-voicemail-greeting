The funniest voicemail greeting a cat would record, in 120 characters or fewer.

> You've reached the cat. I'm pushing your mug off the counter. Leave a message — I'll knock that off too.

## Why this line

A real voicemail greeting in the cat's own voice: it opens with the
greeting formula ("You've reached the cat"), the joke comes from something
specific to cats — knocking things off shelves, here the caller's mug,
mid-push — and the punchline arrives fast and works spoken aloud: "I'll
knock that off too", the message itself the next victim on the floor.
Attitude throughout (the cat narrates its crime live), and a fresh angle
(the voicemail message as the next thing to fall).

## Run it

```sh
python3 main.py
```

`main.py` (pure Python stdlib, no dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a
self-check gate (1–120 characters, single line, not whitespace-only) and a
byte-exact read-back verification.
